# Data Integrity — Quy Tắc Toàn Vẹn Dữ Liệu

1. **Ô Rỗng Có Nghĩa:** Không điền số `0` hoặc chuỗi giả vào ô chưa có dữ liệu.
2. **Quy Tắc Copy Template:** Không tự dựng lại file `.xlsx` hoặc `.md` từ đầu; luôn dùng lệnh copy từ `templates/`.
3. **Quy Tắc Ghi Đè:** Cột `actual_*` bị ghi đè khi đo lường; bắt buộc phải chốt số vào hồ sơ `.md` Mục 9.
